01 / INTRODUCTION

What is a String?

In Java, a String is an object that represents a sequence of characters. We use Strings to store and process text, such as names, messages, addresses and passwords.

Definition

A String is an object of the predefined java.lang.String class used to represent text.

Example

public class Main {
    public static void main(String[] args) {
        String name = "Chandini";
        String language = "Java";

        System.out.println(name);
        System.out.println(language);
    }
}
Output

Chandini

Java

Why do we use Strings?

  • To store names and personal details.
  • To display messages and notifications.
  • To process user input and text files.
  • To compare, search and modify text representations.
  • To work with APIs, websites and database text values.

02 / CREATION

Ways to Create Strings

1. Using a String Literal

String s1 = "Java";
String s2 = "Java";

System.out.println(s1);
System.out.println(s1 == s2);

String literals are stored in the String Constant Pool. When the same literal is reused, Java can reuse the pooled String object.

2. Using the new Keyword

String s1 = new String("Java");
String s2 = new String("Java");

System.out.println(s1.equals(s2));
System.out.println(s1 == s2);

Each execution of new String("Java") creates a distinct String object. The objects contain equal text, but their references differ.

03 / MEMORY

String Constant Pool

The String Constant Pool is a special area associated with the JVM's heap that allows String literals to be reused. Reusing an object can save memory.

01

String Pool

Stores and reuses pooled String instances.

String a = "Hello"; String b = "Hello";

a and b can refer to the same object.

02

Distinct Objects

The new keyword creates a separate object.

String c = new String("Hello");

c refers to a different object from a.

Compare references and content

String a = "Hello";
String b = "Hello";
String c = new String("Hello");

System.out.println(a == b);
System.out.println(a == c);
System.out.println(a.equals(c));

Remember: == compares object references. equals() compares String content.

04 / IMMUTABILITY

String Immutability

Strings in Java are immutable. This means that once a String object is created, its character content cannot be changed. Methods that appear to modify a String return a new String instead. 

String text = "Hello";
text.concat(" Java");

System.out.println(text);

text = text.concat(" Java");
System.out.println(text);
Output

Hello

Hello Java

Why is immutability useful?

  • String values are safer to share between parts of a program.
  • String literals can be reused through the pool.
  • Strings are suitable for values such as file paths and identifiers.
  • Immutable objects simplify reasoning about shared data.

07 / INTERVIEW PREPARATION

Common Interview Questions

1. Is String a primitive data type?

No. String is a class in Java. The primitive types include int, char, boolean, double and others.

2. Why is String immutable?

Immutability supports safe sharing, pooled String reuse and predictable values. It also helps make Strings suitable for security-sensitive values, though it does not make every use automatically secure.

3. What is the difference between == and equals()?

For objects, == compares references. String.equals() compares character content.

4. What is the String Constant Pool?

It is a JVM mechanism for reusing String instances corresponding to literals and interned Strings.

5. Can we change a String after creating it?

No. String objects are immutable. You can assign a new String to a variable, but the original object remains unchanged.

6. What is the difference between StringBuilder and StringBuffer?

Both are mutable. StringBuffer synchronizes its methods, while StringBuilder generally avoids that overhead.

7. What happens when we concatenate Strings using +?

Java evaluates the concatenation expression to produce a String. Repeated concatenation in a loop may be less efficient than using StringBuilder.

8. What is the difference between an empty String and null?

An empty String, "", is a real String object with zero length. null means a reference does not refer to an object.
